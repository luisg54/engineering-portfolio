# Luis Garcia Rivera — Engineering Portfolio (Public-Safe v2)

This folder is a static GitHub Pages-ready portfolio.

## Deploy

1. Replace the corresponding files in the `engineering-portfolio` repository.
2. Keep the folder structure unchanged, especially `images/`.
3. Commit and push to the GitHub Pages branch.
4. Verify all project pages and the resume link after deployment.

## Public-safety decisions

- Internal station names, work-center identifiers, fixture variant names, exact cable lengths, robot programs, production screenshots, internal layouts, drawings, dimensions, and data-system details were removed.
- Tesla project pages use public, stock, or sanitized visuals only.
- Claims distinguish design, fabrication, installation, validation, and production status.
- The stud-welding checking fixture is shown only as an in-progress design released for machining, not as a completed production result.

## Update workflow

Use Engineering OS as the private evidence source. Generate sanitized portfolio proposals, review the exact wording and visuals, then manually merge approved changes into this public repository.
